# Accessibility Assistant Agent

Ye ek AI-powered Accessibility Assistant Agent hai jo Persons with Disabilities (PwD), elderly, aur low-literacy users ko government schemes aur digital services access karne me help karta hai.

## Features
- Sarkari accessibility schemes dhundhna.
- Mushkil text ko simple language me convert karna (Cognitive Accessibility).
- Screen-reader friendly aur accessible UI.
- Voice input / output support.
- Website/Text accessibility evaluation (WCAG basic checklist).

## Setup Instructions
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Create `.env` file aur apni Anthropic API key daalo:
   ```
   ANTHROPIC_API_KEY=your_api_key_here
   ```
3. App run karo:
   ```bash
   python main.py
   ```
   App `http://localhost:8000` pe start ho jayegi.
